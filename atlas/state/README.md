# Atlas Decision State

This directory is reserved for live, date-stamped working state created by Codex runs. Permanent methodology stays in `sources/`; dynamic research state stays here.

Recommended files:
- `decision-journal.md`
- `kill-list.md`
- `watchlists.md`
- `predictions.md`
- `last-run.json`

Do not commit confidential account information, brokerage credentials, or non-public information.
