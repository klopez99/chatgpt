# Skilled Nursing Visit Note Template

Use this for Kinnser-ready SN visit drafting. Keep text factual and based only on observed or nurse-provided information.

```text
SKILLED NURSING VISIT NOTE

Visit Date/Time:
Visit Type:
Patient Alias/Initials:
Primary Skilled Need:

SUBJECTIVE:
Patient/caregiver reports:
Pain:
Changes since last visit:
Falls/ER/hospitalization since last visit:

OBJECTIVE / FOCUSED ASSESSMENT:
Vitals:
Cardiopulmonary:
Edema/skin:
GI/GU:
Neuro/mobility/fall risk:
Blood glucose/diabetes findings if applicable:
Wound/catheter/other focused findings:

SKILLED INTERVENTIONS PERFORMED:
SN performed:
Skilled rationale:
Patient response/tolerance:

MEDICATION REVIEW:
Medications reviewed:
Changes/issues:
Adherence concerns:
MD/pharmacy follow-up needed:

TEACHING PROVIDED:
Education topics:
Patient/caregiver teach-back or response:
Reinforcement needed:

CARE COORDINATION:
Provider/agency/caregiver/therapy/DME/supply communication:
Orders requested or pending:

PLAN:
Continue SN per POC for:
Next visit focus:
Follow-up tasks:

QA FLAGS FOR NURSE REVIEW:
- Verify all vitals and pain score.
- Verify medication names, strengths, routes, and frequencies.
- Verify wound/catheter details and orders if applicable.
- Verify teaching response/teach-back.
- Verify skilled need and homebound relevance.
- Remove any unsupported statements before Kinnser entry/signature.
```

## Common skilled phrases

Use only when supported by the visit facts.

```text
SN assessment and intervention required due to risk for complication and need for skilled monitoring/teaching related to [condition].

Patient/caregiver instructed on [topic], including [specific points]. Patient/caregiver [verbalized understanding / demonstrated teach-back / requires reinforcement].

SN to continue per POC for skilled assessment, disease process teaching, medication review, safety education, care coordination, and monitoring for changes requiring physician notification.
```
